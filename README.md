# House Price Predictor

Predicts California house prices using Random Forest Regression.

## Results
- RMSE: $47,122
- R²: 0.7773

## Stack
Python, pandas, scikit-learn, matplotlib, seaborn

## Steps
1. EDA & data cleaning
2. Feature engineering
3. Model comparison (Linear Regression, Polynomial, Random Forest, Gradient Boosting)
4. Hyperparameter tuning with GridSearchCV
5. Final evaluation on holdout test set

## Dataset
[California Housing Prices — Kaggle](https://www.kaggle.com/datasets/camnugent/california-housing-prices)
